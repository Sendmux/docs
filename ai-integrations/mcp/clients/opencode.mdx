Use this page to connect Qubrics MCP to your AI client.

## Hosted OAuth

Use the hosted endpoint when the client supports remote MCP OAuth:

```text
https://mcp.qubrics.com/mcp
```

Add this to `opencode.json`.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "sendmux": {
      "type": "remote",
      "url": "https://mcp.qubrics.com/mcp",
      "enabled": true
    }
  }
}
```

Authenticate when prompted, or run:

```bash
opencode mcp auth sendmux
```

## Local stdio

<McpUpgradeSafety />

Install the local package once:

```bash
pip install --upgrade sendmux-mcp
```

Use a mailbox key for Mailbox or Sending:

```bash
export QUBRICS_MBX_KEY=smx_mbx_...
```

Use a root key for Management:

```bash
export QUBRICS_ROOT_KEY=smx_root_...
```

Add this to `opencode.json`.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "sendmux-mailbox": {
      "type": "local",
      "command": ["sendmux-mcp-mailbox"],
      "environment": {
        "QUBRICS_API_KEY": "smx_mbx_..."
      },
      "enabled": true
    }
  }
}
```

## Private HTTP

Start a local HTTP MCP server:

```bash
QUBRICS_API_KEY=smx_mbx_... \
QUBRICS_MCP_HTTP_BEARER_TOKEN=local-mcp-token \
sendmux-mcp-mailbox --transport http --host 127.0.0.1 --port 8765
```

Use `http://127.0.0.1:8765/mcp` as the client URL.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "sendmux-local": {
      "type": "remote",
      "url": "http://127.0.0.1:8765/mcp",
      "oauth": false,
      "headers": {
        "Authorization": "Bearer local-mcp-token"
      },
      "enabled": true
    }
  }
}
```
