Use this page to connect Sendmux MCP to your AI client.

## Hosted OAuth

Use the hosted endpoint when the client supports remote MCP OAuth:

```text
https://mcp.sendmux.ai/mcp
```

Add this to `~/.codex/config.toml` or a trusted project `.codex/config.toml`.

```toml
[mcp_servers.sendmux]
url = "https://mcp.sendmux.ai/mcp"
```

Then authenticate:

```bash
codex mcp login sendmux
```

## Local stdio

<McpUpgradeSafety />

Install the local package once:

```bash
pip install --upgrade sendmux-mcp
```

Use a mailbox key for Mailbox or Sending:

```bash
export QUBRICS_MBX_KEY=smx_mbx_...
```

Use a root key for Management:

```bash
export QUBRICS_ROOT_KEY=smx_root_...
```

Run Codex with `QUBRICS_API_KEY` already set, then use `env_vars` so the value stays outside the config file.

```toml
[mcp_servers.sendmux_mailbox]
command = "sendmux-mcp-mailbox"
env_vars = ["QUBRICS_API_KEY"]
```

## Private HTTP

Start a local HTTP MCP server:

```bash
export QUBRICS_MCP_HTTP_BEARER_TOKEN=local-mcp-token

QUBRICS_API_KEY=smx_mbx_... \
sendmux-mcp-mailbox --transport http --host 127.0.0.1 --port 8765
```

Use `http://127.0.0.1:8765/mcp` as the client URL.

```toml
[mcp_servers.sendmux_local]
url = "http://127.0.0.1:8765/mcp"
bearer_token_env_var = "QUBRICS_MCP_HTTP_BEARER_TOKEN"
```

Keep the server running. In the shell where you start Codex, export the same bearer token:

```bash
export QUBRICS_MCP_HTTP_BEARER_TOKEN=local-mcp-token
codex
```
