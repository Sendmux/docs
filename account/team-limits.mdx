Free is intended for testing and small agent workflows. Its limits are fixed. Pro removes plan-level resource count limits and keeps usage-based billing.

Each account can own one active Free team. Every additional active team needs its own Pro subscription or Enterprise agreement.

## Resource limits

| Resource                               | Free               | Pro                                |
| -------------------------------------- | ------------------ | ---------------------------------- |
| Teams per account                      | 1 active Free team | Each Pro team is billed separately |
| Domains                                | 1                  | No plan count limit                |
| Mailboxes                              | 2                  | No plan count limit                |
| Your own or connected sending accounts | 1                  | No plan count limit                |
| Webhooks                               | 1                  | No plan count limit                |
| Credentials                            | 2                  | No plan count limit                |
| Team members                           | Owner only         | No plan count limit                |

<Note>
  Credentials include manual API keys across all key types and connected apps.
  Pending mailbox credential creation can also reserve capacity until it
  finishes. The **API Keys** page shows both credential classes in that total.
</Note>

## Fixed Free limits

Free limits are hard constraints. When a Free team reaches one, the app prompts the owner to upgrade to Pro instead of sending an increase request to an administrator.

API resource creation returns `409 limit_exceeded` at a fixed resource limit. A Free request to `POST /providers/limits/sending-accounts/request-increase` returns `403 insufficient_permissions`.

## At the hard limit

Delete an existing resource or upgrade the team to Pro. Retrying without either change will return the same error.

Existing resources and balances are preserved when a team moves between Free and Pro.

## Email volume

Free teams can send to at most 10 accepted recipients per UTC day across all sending routes. A message with one To recipient and two CC recipients counts as three accepted recipients.

Managed Amazon SES adds these safeguards:

| Plan | Hourly limit                      | Daily limit                         | More capacity                                   |
| ---- | --------------------------------- | ----------------------------------- | ----------------------------------------------- |
| Free | 2 accepted recipients             | 10 accepted recipients              | Upgrade to Pro                                  |
| Pro  | Starts at 100 accepted recipients | Starts at 1,000 accepted recipients | Request a review from **Accounts** at 80% usage |

Pro does not have a Sendmux-wide outgoing volume cap. Managed sending limits, configured quotas, provider limits, and account health controls still apply.
